# 中国首个真正的前沿模型？

![来源：作者使用人工智能](https://cdn.jsdelivr.net/gh/genesislab-io/beatai-assets@f57acaa7f91c273943d513e6df59bec5234b6767/ai-insights/2026-06/21/images/chinas-first-true-frontier-model/01.webp)

时机终于成熟。中国顶尖人工智能实验室之一 Zhipu 发布了一款可能在人工智能领域开创先河的模型，据我所知，这是首个在原始性能上真正能与美国顶级模型相媲美的中国人工智能模型。

不，这并非又一款价格低廉但智能强大的中国模型；我指的是纯粹的性能。这款模型比谷歌迄今为止发布的任何大型语言模型（LLM）都要出色，**甚至在多项基准测试中击败了 OpenAI 最优秀的 GPT-5.5 模型**。

这并非一次普通的发布。这是史无前例的。原因如下。

## 这实际上是第一次

此前的中国模型，如 DeepSeek v4，虽然展现出一定的潜力，但在大多数基准测试中明显落后。

别误会我的意思，它们确实不错，而且在很多情况下，**对于特定任务来说已经足够好了，同时所需的投资却少几十倍，**但在几乎所有基准测试中仍然落后于美国领先水平。

*但为什么这个模型有所不同呢？*

### 大卫对战歌利亚

今天的主角 **GLM-5.2** 是由 Zhipu AI（即 Z.ai）开发的模型，Zhipu AI 是中国主要的人工智能实验室之一。

根据 Z.ai 公布的基准测试结果，它在 SWE-bench Pro 测试中获得了 62.1 分，高于 GPT-5.5 的 58.6 分和 GLM-5.1 的 58.4 分；在 Terminal-Bench 2.1 测试中获得了 81.0 分，比 GLM-5.1 的 62.0 分有了很大的提升，**使其与最强大的专有模型处于同一编码级别，同时又是一个开放模型**（这意味着您可以免费下载它）。

FrontierSWE 的说法最为有力：**据报道，GLM-5.2 的得分为 74.4%**，仅次于 Claude Opus 4.8 的 75.1%，领先于 GPT-5.5 的 72.6%，并且远远领先于 Opus 4.7。

该模型仅比 Opus 4.8 落后 1%，比 GPT-5.5 略胜 1%，比 Opus 4.7 领先 11%。

或许最大的输家是谷歌，**几乎所有基准测试都显示谷歌被彻底击败**，而击败它的模型据推测规模小得多、训练数据量也少得多，按理说谷歌本应轻松取胜。但事实并非如此。

在人工智能生成的网页设计的一个特定基准测试中，**该模型甚至超过了 Fable**，而 Fable 是最近被美国政府封禁的 Anthropic 模型。

提醒一句，这些数据仅供参考，因为正如我常说的，**基准测试永远无法说明全部情况**，所以真正应该让人们意识到这并非一次普通发布，而是来自实际研究人员/领导者的反应。

*但这怎么可能呢？*

### 秘密在于，根本没有秘密。

从架构上看，这个模型与我们之前见过的所有模型都非常相似。它是一个 Transformer，几乎与 Claude 或 ChatGPT 完全相同。

秘密在于根本没有秘密；**我们知道他们是怎么做到的，因为他们告诉我们了**。

就像其他中国模型一样，**它们使用稀疏注意力机制**，特别是与 DeepSeek 使用的稀疏注意力机制相同（恰如其分地命名为 DeepSeek 稀疏注意力机制），这是美国模型与中国模型之间最大的区别。

*但这究竟意味着什么？*

如今大多数 LLM 的工作原理都一样：接收一系列词语作为输入，输出下一个词语。例如，你给模型输入“美国第 20 任总统 James Garfield 最喜欢的食物是什么？”，模型会回答“松鼠汤”。

> 顺便说一句，这确实是事实。

![](https://cdn.jsdelivr.net/gh/genesislab-io/beatai-assets@f57acaa7f91c273943d513e6df59bec5234b6767/ai-insights/2026-06/21/images/chinas-first-true-frontier-model/06.webp)

*但它是如何做到这一点的呢？*

它做两件事：**注意力（attention）**和**内省（introspection）**。

- **注意力** 是一个过程，模型会获取序列中的每个单词，回顾并询问：“前面的单词是否有任何有意义的信息可以让我关注？”（例如，“绿色的杯子”中的“杯子”关注“绿色”，从而获得“绿色”的属性）。
- **内省**是指模型“查询自身知识”的能力。就像你可以利用记忆来回忆某个事实一样，它们也可以。

从序列中获取上下文并添加知识信息的过程会重复多次，对于最大的模型来说甚至会重复数百次，**这就是为什么我们说这些模型被分成“层”的原因。** 但这些层只是按顺序多次重复这个过程，直到模型弄清楚下一个词应该是什么。

例如，假设我们有这样的序列：“德国的首都是什么？”。最初，模型并不知道你在问什么，所以它开始使用这种注意力机制；“德国”会关注“首都”，这样模型就知道你在谈论德国的首都。然后它会关注“是什么”，这时模型就知道你在问一个问题。

现在，它知道你的意图，也知道你询问的主题。

然而，答案并不在序列中，所以它要么知道答案，要么不知道。因此，它需要调动自身的知识。这并非一蹴而就（注意力也是如此），**因此必须通过多次连续重复才能完成。**

综上所述，你可以将整个过程看作是模型逐步收集更多背景和认知证据，直到它最终“知道”它是哪个词：“柏林”。

> 两者都是相当吃力的计算，需要大量算力，这也解释了为什么人工智能需要如此昂贵且强大的芯片。
>
> 如果你好奇的话，对于短句，内省通常占据计算主导地位；对于长序列，则是注意力更耗算力。随着世界向智能体（超长文本序列）发展，注意力将成为瓶颈。

然而，对于今天的主题，**我们只关注注意力部分**，因为美国和中国模型的内省部分完全相同，甚至连逗号都一样，所以这方面没有什么可说的。

而关键区别就在于他们如何“回顾过去”。

### 需要投入多少精力？

假设你有以下序列：“那个绿色的，嗯，呃，嗯，啊，是的，杯子，是……”

如果注意力是为了发现词语之间的关系以构建对文本序列的理解，那么“杯子”是否需要关注“嗯”或“呃”，还是应该只关注“绿色”？

*这些特定的词语有价值吗？* ***或者可以忽略这种关系，从而节省计算成本？***

大多数情况下，至少对于美国前沿模型来说，我们不会问这些问题，只是执行密集注意力（dense attention）；**每个词都关注其他所有词，不加区分**。

这确保了所有关系都能被发现，**但代价是需要大量的计算资源**。在我们之前的例子中，“ehhh”和“uhhh”会被所有后续单词所关注。

你可能已经猜到了，中国实验室（其计算能力远不如美国实验室）在这里应用了最大的成本节约措施，这也是中国模型更便宜的原因之一（尽管并非唯一原因，我们稍后会看到）：**稀疏性**。

换句话说，“稀疏”模型实际上假设并非所有词语都值得关注。因此，**这些模型首先进行“扫描”，选择“重要的词语”，然后才对这些词语进行处理。**

这体现在一个**索引器**中，它会选择特定词可以关注的候选词，并设定一个限制。例如，如果索引器只允许关注 20 个词，而你之前有 1000 个词，那么**每个词只会关注它最有可能关注的前 20 个词。**

我不确定这个比喻是否恰当，因为我不是神经科学家，也不确定人类是否有“索引器”。所以，从人类的角度来看，最接近的比喻是用荧光笔阅读。

想象一下，你正在阅读一份长达 1000 页的法律合同，有人问你关于其中某个条款的问题。最费力的回答方式是每次被问到问题时，都逐行仔细地重新阅读这 1000 页的内容。这就是密集注意力（dense attention）：每个词都可以关注它前面的每一个词。

但人类很少这样工作。首先，我们会快速浏览。我们会查看标题、关键词、重复出现的人名、日期、格式以及大致的语义线索，以此判断哪些页面可能相关。**只有在确定相关内容之后，我们才会仔细阅读这些选定的页面。**

稀疏索引器扮演着类似的角色。在模型花费实际计算资源将当前词与所有先前的词进行比较之前，索引器会询问：“哪些先前的词块可能很重要？” 然后，它会选择一个有限的候选词块集合，**并且全部的注意力计算都只用于这些词块。**

这使得执行注意力所需的计算量在每个单词的序列长度上保持“恒定”，**性能仅略有下降**，这使其成为中国实验室不可抗拒的选择，正如前面提到的，中国实验室的计算能力远不如美国实验室。

> 相比 DeepSeek 的模型，GLM-5.2 增加了一项名为 [**IndexShare**](https://arxiv.org/pdf/2603.12201?utm_source=thewhitebox.beehiiv.com&utm_medium=newsletter&utm_campaign=china-s-first-frontier-model&_bhlid=4824a3dcd92634dda1f75772ce6841a2400652d1) 的额外算力节省技术。DeepSeek 模型在每一个模型层都应用索引器，而 GLM-5.2 仅每隔几层应用一次索引器，从而避免这个“候选识别”过程被执行多于必要的次数。在长序列中，**这能把算力减少近 3 倍**。

如果您想深入了解这种索引器机制以及稀疏注意力（以及一般的注意力机制）的整体运作方式，[***我在这里写了一篇非常详细的描述***](https://medium.com/@ignacio.de.gregorio.noblejas/deepseek-is-finally-back-solving-sparse-attention-d2ebbcb8ecb2?sk=6bbf2467f61303a14244ee7eec2b304d&utm_source=thewhitebox.beehiiv.com&utm_medium=newsletter&utm_campaign=china-s-first-frontier-model&_bhlid=16a13b9dfd41d711dfe6230e57102e5c3bce86d9)。

所以，*结束了吗？中国赶上了吗？* 嗯，情况很复杂，但原因并非显而易见。

## 不，但这无关紧要。

不，**中国还没有赶上**。这并不是问题的关键所在，因为这显然是错误的。

更复杂的是，这根本无关紧要。

### 一个充满极端的世界

即使在今天，我仍然不断听到诸如“*中国落后一年*”之类的妄言。我认为这个模型已经证明这种说法大错特错。

但社交媒体上的叙事总是走向极端以博取关注，所以你要么属于这种阵营，要么属于“中国已经赶上来了”阵营，而这也不是事实。

**关键区别，真正的差距在于泛化能力**。中国实验室的计算资源远不及美国实验室，**因此在泛化能力上无法与美国模型匹敌**；它们的模型规模较小，训练预算也少得多。

这意味着他们不得不偷工减料；事实就是如此。而且我仍然认为，只要当前的模式保持不变，即人工智能的发展主要由计算（包括训练和推理）驱动，**中国就无法赶上。**

但这并不意味着他们没有竞争力，因为他们完全可以。为了做到这一点，**他们专注于特定领域（主要是编程），以便在特定的、高价值的任务中具备竞争力。**

[**下面是这个问题的一个简单例子**](https://x.com/nikhilchandak29/status/2066970561511657913?utm_source=thewhitebox.beehiiv.com&utm_medium=newsletter&utm_campaign=china-s-first-frontier-model&_bhlid=890edff01b65dcbd6ddcb975da72f6c65b4a8df4)，一个名为 **FutureSim** 的基准测试 使用真实的新闻文章等数据来衡量模型预测训练后发生的未来事件的能力。其核心思想是测试模型能否有效处理新信息。

在这种情况下，对于那些需要模型处理真正未知数据（即泛化）的情况，**封闭模型和开放模型之间的性能差距巨大**，这证明中国模型在中国研究人员决定关注的特定领域取得了优异的性能，但与美国顶级模型相比，总体上存在明显的不足。

![](https://cdn.jsdelivr.net/gh/genesislab-io/beatai-assets@f57acaa7f91c273943d513e6df59bec5234b6767/ai-insights/2026-06/21/images/chinas-first-true-frontier-model/07.jpg)

> 但关键在于：**中国整体能力是否赶上并不重要**。重要的是**中国模型是否达到了可被使用的能力门槛**，同时价格却低 10 到 60 倍。

我以前说过，现在再说一遍，**企业**，那些旨在为所有这些庞大的人工智能赌注支付账单，以确保它们不会崩溃的企业，**需要的是深度模型，而不是通用模型**。

他们渴望的是专业化的模型，却丝毫不关心人工智能模型是否擅长处理当前任务以外的其他任务。

> 泛化是推动前沿的关键，但对落地应用并非如此。

而且它们在许多领域都达到了这个门槛，**使它们成为经济高效部署的首选**。

这对美国利益来说是个糟糕的消息；美国放任中国主导帕累托前沿的做法令人深感担忧，尤其是我坚信**几年后大宗商品级 token 将占所有生成 token 总量的至少 80%**。

如果说在这个行业中有什么事应该被视为美国的国家安全问题，那就是这件事了。而解决这个问题的唯一办法就是竞争。

Artificial Analysis 智能指数的绿色象限（该象限按智能/成本比展示最具吸引力的模型）完美地说明了这一点，揭示了中国模型在这一维度上令人难堪的统治地位。

![来源：Artificial Analysis](https://cdn.jsdelivr.net/gh/genesislab-io/beatai-assets@f57acaa7f91c273943d513e6df59bec5234b6767/ai-insights/2026-06/21/images/chinas-first-true-frontier-model/08.webp)

> 而现在，**这意味着如果美国实验室不采取行动，未来全球 80% 的 token 将很快源自中国模型。**

*但美国又能做些什么呢？*

首先，冒着陈述显而易见之事的风险，**美国实验室应该在中等规模这一档拿出更强的竞争力**。像 NVIDIA 的 Nemotron 3 Ultra 这样的选项很有潜力，但相比中国正在做的，它们仍然像一次相当薄弱的联合努力。

在此，**我希望美国政府向这些实验室施压，促使它们发布更多公开的研究成果和模型**，尤其是在这些实验室期望从政府获得资金支持的情况下，而我认为这种情况最终会发生。这种资金支持不应该是免费的，政府应该迫使这些实验室做出相应的回报。

如果说有什么值得称道的，那就是这些实验室一旦上市，**至少应该有点良知，在窃取了我们所有数据之后有所补偿**。不过，也许这只是我个人的想法，如果我是他们，我也会这么做。

但美国政府还可以做另一件触及我最关心的问题核心的事情：**资本成本**。

### 资本缺口

人们认为中国在补贴 token 价格。不，事实并非如此。我们确信这一点，因为同样的中国模型在美国推理服务提供商那里也以几乎相同的价格运行。

它是在补贴基础设施建设。

在评估 token 的总拥有成本 (TCO) 时（生成式 AI 模型按 token 收费，token 可以是聊天机器人中的一个词、图像中的一个像素块等等），**总成本的 90% 或更多是资本**。

OpenAI 或 Anthropic 生成的每个 token 中，只有大约 10% 是服务该 token 的成本，**而 90% 来自投资成本**。

这彻底改变了现状。众所周知，每 1 吉瓦的计算能力需要 500 亿美元的资本投入。但在最近的 Computex（台北国际电脑展）上，**NVIDIA 首席执行官 Jensen Huang 预测，这一数字将增长至 1000 亿美元/吉瓦，翻一番。**

因此，**我始终坚持认为 token 价格上涨主要是由于资本成本上涨**；看到 NVIDIA 收入环比增长 50%，同时毛利率保持在荒谬的 75%，这对除 Jensen 以外的所有人来说都是坏消息。

但就中国而言，情况则完全不同。

根据一份报告，中国同类设施的建设成本（不含加速器）约为每吉瓦 60 亿至 100 亿美元，而美国一座设备齐全的前沿人工智能数据中心的建设成本约为每吉瓦 500 亿美元。**中国的建设成本和电力保障成本要低得多，大约只有美国的一半。**

当然，这并非完全可比，而且缺失的变量是芯片成本。但这些芯片也便宜得多。

> 这意味着每个中国 token 承担的资本成本要低三倍。考虑到资本成本占全球总成本的大部分，难怪它们更便宜！

综上所述，我的主要政策建议是：想办法大幅降低目前的资本成本，使美国实验室在定价方面更具竞争力。

否则，恐慌很快就会到来。
