# 以价值为导向：一个不存在的信号

单个功能很容易管理。一个人就能把它装进脑子，大致清楚它为何重要、是否值得做，无需任何机制就能决定。问题在于，工作不会一直保持这么小的规模。一项大型计划、一个项目组合、一整年里相互竞争的各种需求，最终都会越过某个临界点——没有人能够再一次性掌控全局；到那时，就需要某种东西来代替原本由一个人做出的判断。

几乎出于本能，人们会伸手去抓"价值"。衡量它，以它为导向，让数字来承载那些再也装不进一个人脑袋里的决策。这并非愚蠢之举，而是合情合理之举，正因如此，它才值得拆开来看。在最需要它的那一刻伸手抓来的东西，恰恰无法胜任这项工作。原因并不是价值难以衡量，而是"价值"这个词在被抓取的那一刻，悄悄地在做两件不同的工作，而其中只有一项被要求去做它无法胜任的事。

## 这个词的两种作用

想象一场项目组合评估。有人审视一项计划，问道："这有价值吗？"这句话很普通，答案却可能指向两种截然不同的东西。

在第一层意义上，价值是一种*控制信号*：它是你每个周期都要读取的数值，用来闭合反馈回路——就像一个表盘，如果你能在这项工作上装一个，它会显示的读数。你盯着这个数值，一旦它朝错误的方向移动，就加以修正。这就是作为转向机构输入的"价值"，被持续参考，是驱动整个系统的那个量。

在第二层意义上，价值是一种*有人担责的判断*：一个负责任的人审视自己无法衡量的东西，做出决断，指明由谁来担下随之而来的这一赌注，然后推进。这是一次性的行为，而非持续的读数。它并不假装自己是一种衡量，而是一个人把自己的名字押在一项决定上，并把它担下来。

接下来要讨论的只有第一层意义。第二层意义在本文的所有论证中都能幸存；它是必要的、正当的，也是负责之人存在的意义所在。它只是理应置于控制回路之外，而非之内——这一点将在后续文章《你唯一能掌控的决定》¹中展开。眼下的重点更窄也更尖锐：这两层意义在种类上就不同，这片领域里几乎所有的混淆，都源于在两者之间来回滑动——要么借用"有人担责的判断"的体面，来为持续的操控信号背书；要么借用这种信号表面上的严谨，来粉饰原本只是一个判断的东西。

于是为本系列余下部分立一条规则，对读者和作者同样有约束力：从这里起，这个词每次出现都指定其中一层意义，而两层意义之间的滑动，正是要提防的动作。

这个领域本身就在含糊其辞，而且它含糊的地方还有个标准化的名字。挣值管理（Earned Value Management）是一项已有数十年历史的技术，名称里带着"价值"二字，衡量的却是完全不同的东西。它的核心量——挣值——被定义为"以已批准预算表示的、已完成工作的度量"。² 这其实是对计划的符合度。它的两个招牌指数读法相同：成本绩效指数是挣值除以实际成本，进度绩效指数是挣值除以计划值，因此两者报告的都是相对于既定基线的成本效率与进度符合度。一个项目可以把这两个指数都稳稳保持在 1.0，同时造出没人想要的东西。在任何论证开始之前，词汇就已经含糊了。这就是挣值管理在这里的全部用处；这项技术本身并非研究对象，也不是靶子。它只是一件现成的标本：一个词披着价值的外衣，读出来却是成本。

## 控制信号必须是什么

如果价值要充当控制信号，也就是驱动反馈回路的那个东西，那它就得满足任何此类信号都要满足的要求。要求有三条，而价值以三种不同的论证，各自落空。

控制信号必须*在回路的时间尺度上可观测*。你不可能靠一个要等好几个季度才显现的读数，去在每个周期做出修正。价值立刻就在这一条上落空。它既滞后又受到混淆：一项功能本月发布，而它带来的任何收入或留存都要晚得多才会出现，还与一次调价、一轮季节性波动、竞争对手的一个动作以及其他十几件同时进行的事情难分难解地纠缠在一起。等到信号最终显现，它早已不再挂靠在那个据称引发它的行为上。它脱离了回路。

控制信号必须*可归因于具体行为*。操控意味着知道这一步动作产生了那个结果。而在这里，价值落空并非因为努力不够，而是由它的构造本身决定的——因为你需要观察的是一个反事实：假如你没有采取这一行动，会发生什么。这种比较在原则上就无法观察。它的正式表述由来已久且十分精确：因果推断的根本问题在于，你永远无法在同一个单元上同时观察到两个潜在结果——采取行动后的结果，和不采取行动的结果——因而永远无法直接观察某个原因对该单元的作用。³ 你看到的是你发布了这项功能的那个世界；而你没有发布它的那个世界，已经消失了。那个具体赌注的价值，恰恰就是两个世界之间的差；而这个差，是拿不出来衡量的。

控制信号必须*经得起被人拿来优化*。一旦某个价值度量成为组织被其操控的那个东西，它就不再衡量价值，而开始衡量人们对这个度量动了什么手脚。"当一个度量成为目标，它就不再是一个好度量。"⁴ 这不是可以靠设计更精巧的指标工程掉的缺陷。这就是"用指标来操控"本身。分数会被一切能过关的东西填满，而分数与它所代表之物之间的差距，会随着分数被当真的程度成比例地扩大。

正是这里的结构，让这套拆解很难被击败。这三个失败彼此独立——它们不是同一个反对意见说了三遍，而是三个不同的论点，对手必须把三个全部驳倒。其中之一，归因，是在原则上、而非在实践中落空的；接下来要压上最重分量的，正是这条腿。

## 为什么更严谨也帮不上忙

对此最自然的回应，就是伸手去求精确。把它衡量得更好。增加评判标准。采用更成熟的框架。问题肯定出在衡量太粗糙，一件更精细的仪器就能把差距合上。

它合不上，原因是结构性的。被衡量的东西是一个反事实，而反事实无论仪器多精细都无法观测。你没法提高对一个根本不在场、无从衡量之物的衡量精度。给一个不可观测之物加上严谨，并不会向真相收敛；它制造的是虚假的精确——被打扮成衡量的估计——这比诚实的无知更糟，因为诚实的无知不会被人辩护，而一个数字会。真正值得记住的一句话是：更多细节只会让代理更锋利，却对代理与它所替代的那个反事实之间的差距毫无作用，而误差就住在那个差距里，任何分辨率都够不着它。

既然本节重重压在"类型"这个词上，那就值得用同样的审视来对待本文自己提出的主张。这个主张是：价值作为控制信号的失败，是一种类型错误，而不仅仅是难度问题；而诚实要求承认，这三条腿并非同等地配得上"类型"这个词。归因这条腿配得上：Holland 所说的不可观测性是原则上的，而不是仪器质量的问题——这是种类上的差别。脱离回路这条腿和操纵这条腿虽然严重且是结构性的，但它们更接近"实践上非常困难"，而不是"原则上不可能"。所以，"类型错误而非难度"这个强框架，最重地压在归因上；而三条腿则同时支撑着那个较弱、但仍然足够的主张——价值不能充当控制信号。把这点挑明并不会削弱论证，反而表明：类型主张是在真正要紧的那条腿上经受住了对自身的审视，而不是被均匀摊派到三条各自都撑不住它的腿上。

尾巴上还带着一根刺。量化手段越是雄心勃勃，就越危险，因为它给操纵和虚假精确增添的是更多、而非更少的权威。对一个不可观测之物施加严谨，只会抬高信心，却不会抬高正确性；而这种背离——信心节节攀升，正确性却原地不动——正是这桩指控的要害。

## 一个根，三个面

人们很容易把这三个失败当成需要逐一削减的独立障碍：这里一个衡量问题，那里一个操纵问题，还有一个绕着建模就好的归因问题。它们无法分开，因为它们是同一个现象从三个角度看到的样子。

顺着这条链看。归因失败，因为价值是一个反事实，所以你退回去依赖估计。估计是披着数字外衣的判断，而这正是招来操纵的东西。操纵是人们对着信号、而不是对着世界行动，这正是政治维度接管整场演练的原因。每一环下面都坐着同一个事实：价值是一个不可观测的反事实，而下游的一切都是人们围绕一个不可观测之物讨价还价。衡量从一开始就无从了断此事，因为那里根本没有东西让衡量落脚。

这就是为什么你没法修好一个面而不让其他面重新冒出来。收紧估计，政治就直接搬到设定估计的地方去。管住操纵，它就迁移到指标的定义上。这些面并不是可以逐个修补的独立漏点；它们是同一个根在三个地方透出来。一场优先级排序会议，若价值分数明显是谁争得最凶所留下的残渣，那它展示的并不是两个问题——一个政治问题加一个估计问题。它展示的是同一个问题，两遍。

## 可衡量性反比律

从这同一个根落下一条值得单独陈述的规律：随着战略分量上升，可衡量性下降。

这个机制并不神秘。那些价值你一眼就能读出的工作，系统性地正是最不需要操控的工作：层级低、技术性、局部耦合，从改动到其效果的路径既短又清晰可读。而真正承载战略分量的工作——一次市场进入、一次平台押注、一次方向转变——恰恰是价值最难读出的工作，因为从决策到任何结果的路径要穿过数年时间，还要穿过世上正在发生的其他一切。这两种属性朝相反方向移动，是结构使然，而非巧合。

这对整套做法来说都很尴尬。基于价值的操控，恰恰在最不需要它的地方最为严谨，又恰恰在最需要它的地方最不可得。这使它成为一种瞄准了错误目标的方法，而不是一种瞄准正确目标、只是带点毛边的稳妥方法。而这条规律，早在那个显而易见的反例被抛出之前，就先把它化解了：价值导向看似奏效的那些案例，正是风险一直低到耦合始终很短的案例。这不是一处需要辩解掉的让步；它就是本文收束于其上的边界，值得稍后把它说精确。

## 实用主义者的反驳

这里最强的对手，并不是那个坚持衡量可以做得足够严谨的人。那个立场已经输了。最强的对手是实用主义者，而实用主义者说的话更难回答。

实用主义者指出，一切都是代理。流动指标是代理，价值指标也是代理。周期时间同样不是你真正在乎的东西；它只是个替身，跟价值分数一样。所以这整场争论根本不是认识论，而是对一组代理相较另一组代理的偏好，被打扮成了原则之争。凭什么"用流动代理来操控"就比"用价值代理来操控"更站得住脚？挑一个你那不完美的数字，别再假装哪一个更纯粹了。

第一步，是把必须让的都让掉，因为这个让步不花任何成本。流动并不是我们最终真正在乎的东西，我也无意把它当作*价值的更好代理*来辩护。那种辩护正是会输的一种，应当被干脆拒绝。

真正的答案，是拒绝这个代理框架，而不是试图在框架内部取胜。流动指标是对一个真实对象——系统自身的行为——的直接读数。在制品、周期时间、吞吐量、某个工作项的存留时长，全都是这台机器的可观察属性，而且它们本身就是我们想要的。无论穿过机器的某个具体工作项最终值不值钱，你都希望这台机器可预测、不淤塞。价值指标则完全是另一类东西：它是对某个无法直接观察之物的代理读数，而它恰恰在"代理"这一步就失败了，因为它所代理的，正是那个根本不在场、无从读取的反事实。所以区别不在于流动是同一个底层量的更干净的替身；而在于流动读的是另一个对象——一个可观察的对象，价值读的则是一个并不存在的信号。

这一点至关重要，因为说"流动是更有原则的价值代理"，恰恰会招来实用主义者正在钓的那句反驳：你不过是把代理链在少一环的地方停住，然后把自己的停点称作"直接"。站得住脚的，是那个更强、也更古怪的主张：流动并不是价值的更好代理，它读的是另一个东西，且为其自身之故而被需要。该记住的画面是两个表盘。一个忠实地读机器，你每看一眼它都告诉你一件真事。另一个什么都没接，它的指针会动，是因为有人在拨它。两者之间的区别是种类之别，而非质量之别。

而这个答案是有代价的，且明明白白地付出：它意味着你根本不是在以价值为导向。而这恰好就是本文的论点，所以这代价等于没有代价。不过它确实留下一个问题：如果流动并不是在代理价值，那它到底是干什么用的？它有一份工作，而且是实打实的工作，只是这份工作要在别处搭建——在《你可以否决一个赌注，却无法确认一个赌注》¹里。眼下，只要知道流动的那份工作，并不是实用主义者所以为的、它正在其上失败的那一份，就够了。

## 边界：耦合距离

一个扁平、总括一切的主张，比一个自己画出边界的主张更容易被攻击。所以，值得点名那个决定"价值导向究竟何时能奏效"的变量，并从内部把边界画出来。

以一个内部 IT 部门为例。它在结构上比几乎任何人都更适合去"以某种近似价值的东西来操控"，原因很具体：它能衡量它存在的意义所在、也正是它要去改变的那样东西——业务流程。流程周期时间、错误率、人工介入、返工，全都可以直接衡量。流程成本由它们经算术推出，钱再由流程成本推出。从"被改动的东西"到"钱"的这条链很短，而且其中每一环都是机械的，而非行为性的。

这种方法奏效的真正原因，并不是笼统一句"可衡量性更好"。而是因为归因问题——那三个失败共同的根——在这里从结构上就更小，因为反事实几乎坍缩为一。把一套发票流程通过删掉三个人工审批步骤来重做，由此产生的吞吐量变化就可以归因于这次改动，因为在干预与读数之间，没有任何会造成混淆的市场、客户心理或季节性因素挡在中间。没有这次改动的世界，和有这次改动的世界，彼此靠得足够近，以至于两者之差在实用意义上是可观察的。这并不是根本问题上的一个漏洞；而是那个公认的条件——因果效应在此条件下变得可估计：一次受控的改动，在原因与被测效应之间几乎没有任何东西阻隔。⁵

因此，这个论点与其说成一堵墙，不如说成一段梯度。价值导向的可行性，与"你能衡量的系统"和"你所在乎的价值"之间的耦合距离成反比：对于改动一套自己能直接测量的流程的内部 IT，这段距离短；对于被抛向一个它只能靠猜的市场的产品，这段距离长。这会把那个显而易见的反对意见吸收进来——那次带回了真实、可衡量金额的企业软件上线——而不是否认它。那个案例之所以奏效，是因为它满足了前提：耦合短、反事实几近坍缩、流程被直接衡量。它是边界案例，而非反驳。

需要小心的一点是，这一切都没有突破论点。内部 IT 衡量的是*流程*，那是系统的一个属性，而不是它自身的价值本身。它并没有解决价值衡量；是它所处的领域，恰好为一个特定的、局部耦合的问题递给了它一个异常忠实的代理。这是"操控系统"这一姿态在任何地方能找到的最有利条件下仍然站得住——这是对该姿态的一次确证，而不是对它的一个例外。而就在 IT 干完活的那一刻，同一条线又冒了出来：它能衡量自己释放出的产能；却无法衡量组织拿这些被释放的产能去做了什么，因为那又跑回到了与其他一切长耦合的世界里。企业随后不肯重新部署的闲置产能，是组织的问题，不是 IT 的问题——就像一个客户买了软件、用它创造了价值、然后又把这价值扔出窗外，这并不能否定那款软件。这条边界——在"可衡量的增量"与"拿它去做了什么"之间——正是贯穿后文一切的那条"操控系统、并把赌注担在自己身上"的线，它会在每一个尺度上再次现身：作为一条交付回路能证伪哪些前提的上限，也作为任何一次探测其成本的下限。

那么，这就是这个主张的形状，而边界并不是逃出它的出口。价值不能充当控制信号。这是一个类型错误，而不是一个难度评级；而代理链短到足以让操控"看上去像是奏效"的那唯一一种情形，正是短耦合距离的情形。这就留下了那一大块尴尬的余数：所有那些从一开始就不在价值轴上、却被硬按着去假装自己在价值轴上的工作。
